# ERO SOUND PAD — Starter v0.1.0

## Upload
Extract this ZIP, then upload the files and folders into the root of your existing `ero-sound-pad` GitHub repository. Commit to `main`.

## Enable GitHub Pages
Repository → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save. Wait for the published Pages URL.

## Included
- Responsive eight-pad interface
- Web Audio generated demo drum tones
- Master volume and stop/mute control
- Web MIDI input request and MIDI Learn (browser support varies)
- Basic PWA manifest and offline cache

## Important
This is a starter prototype, not the finished commercial sound module. It uses generated demo tones, not recorded WAV sample kits. Persistent mappings, WAV loading, velocity layers, choke groups, advanced polyphony/latency work, and a native Android USB MIDI bridge are not yet included. Browser Web MIDI support varies; test the actual USB OTG OctaPad and Android browser. Reliable Android USB MIDI may require a native Android bridge.
